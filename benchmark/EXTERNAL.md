# External and generated test sets

The messy-notes benchmark and the clinical-preservation set were written for
this project. These sets come from elsewhere, or are generated by code, so
the tool is also measured on writing, formats and names it was not built
around. Results are in [RESULTS.md](RESULTS.md).

| Set | Source | Licence | What is scored |
|---|---|---|---|
| `aci` | ACI-Bench clinical notes, train and validation (Yim et al., *Sci Data* 10, 586, 2023), [github.com/wyim/aci-bench](https://github.com/wyim/aci-bench) | CC BY 4.0 | Every occurrence of the patient's first and last name (from the set's metadata) |
| `presidio` | Microsoft presidio-research synthetic PII data, `synth_dataset_v2.json`, [github.com/microsoft/presidio-research](https://github.com/microsoft/presidio-research) | MIT | Labelled identifiers in general (non-clinical) sentences; Safe Harbor types scored, others shown for information |
| `tw` | Taiwan synthetic clinical notes with PHI labels, test split, [github.com/fireman333/tw-synthetic-clinical-notes-phi](https://github.com/fireman333/tw-synthetic-clinical-notes-phi) | CC BY 4.0 | Labelled identifiers in Traditional Chinese mixed with English; outside the tool's design (English), shown to make that limit visible |
| `mixed` | Generated by `tools/make_mixed_set.py` (this repository) | Apache 2.0 | Every identifier and clinical phrase placed by code; names from Faker (30 locales), invented names, and a few non-Latin names |

The external files are not copied into this repository. To fetch them:

```bash
mkdir -p ext/presidio ext/aci ext/tw
R=https://raw.githubusercontent.com
curl -o ext/presidio/synth_dataset_v2.json $R/microsoft/presidio-research/master/data/synth_dataset_v2.json
for s in train valid; do
  curl -o ext/aci/$s.csv          $R/wyim/aci-bench/main/data/challenge_data/$s.csv
  curl -o ext/aci/${s}_metadata.csv $R/wyim/aci-bench/main/data/challenge_data/${s}_metadata.csv
done
curl -o ext/tw/test.jsonl $R/fireman333/tw-synthetic-clinical-notes-phi/main/data/test.jsonl
python tools/make_mixed_set.py --out ext/mixed --seed 77031 --n 400   # needs faker
python tools/eval_external.py ext
```

## How these sets are used

- **First run, then fixes, then a fresh set.** The first measurement on each
  set is reported as it was. Fixes for what it showed were tested on a newly
  generated mixed set with a different seed (77031), which nothing had been
  tuned on. The external sets cannot be regenerated, so their later figures
  are marked as measured after fixes informed by them.
- **Faker names favour the tool.** Its name list was built partly from
  Faker; the mixed set therefore also uses invented names that are in none of
  the tool's lists, and reports both separately.
- **Limits.** The generated notes are built from templates and can read
  unnaturally; the ACI-Bench score covers patient names only; the presidio
  sentences are not clinical and include many non-US formats.
